# Contributing

Read the repository README and follow any project-specific contribution instructions. For a substantial change, discuss the problem and expected outcome with the maintainers before implementation. Keep the pull request focused and describe how you verified the change, including any checks you could not run.

Use synthetic or redacted examples. Keep credentials, client records, learner details, and incident or survivor information out of issues, pull requests, and test assets. For security findings, use the repository’s Security tab and follow its reporting guidance. Respect the repository’s stated license and contribution terms.

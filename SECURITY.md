# Security reporting

Open the affected repository’s **Security** tab and choose **Advisories**. Use **Report a vulnerability** when available. If that option is unavailable, use a private security or maintainer contact published by the project. If none is listed, ask a maintainer for a private reporting route and keep the finding out of public threads.

In the private report, identify the affected version or commit, the affected feature, the impact, and supporting evidence with sensitive data removed. Keep credentials, production records, and personally identifying information out of reports. Consult the affected repository for any version-specific support policy.

# Code of conduct

Treat contributors and users with respect. Discuss ideas and evidence without personal attacks. Harassment, discrimination, threats, and sharing someone’s private information without consent are unacceptable.

If an incident occurs in a project space, use GitHub’s reporting tools for abusive content or accounts. You can also contact a project maintainer privately using a contact they have published. Share sensitive details only through private channels. Project maintainers may remove content, limit participation, or block accounts where they have moderation access.
